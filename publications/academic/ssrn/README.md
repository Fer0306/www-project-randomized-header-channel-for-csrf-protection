### RHC Protocol: A Randomized Header Channel for CSRF Protection at the Communication Integrity Layer

**Autor:** Fernando Flores Alvarado
**Afiliación indicada en la publicación:** OWASP
**Fecha de publicación:** 3 de junio de 2026
**Fecha del manuscrito:** 20 de mayo de 2026
**Estado:** Publicado

### Resumen

Primer documento académico público del proyecto RHC Protocol Core.

El trabajo presenta el protocolo Randomized Header Channel (RHC) como una propuesta orientada a fortalecer la protección contra CSRF mediante la introducción de una capa de integridad de comunicación denominada Communication Integrity Layer (CIL).
